# Slotik — Frontend

Клієнтська частина платформи онлайн-запису до майстрів сфери послуг.
React + Vite + TypeScript + Tailwind CSS. Бекенд: [Slotik](https://github.com/Zethusik/Slotik).

## Запуск локально

```
npm install
npm run dev
```

Відкрити http://localhost:5173

## Структура

- `src/pages` — сторінки (маршрути)
- `src/components` — перевикористовувані компоненти
- `src/api` — запити до бекенду
- `src/hooks` — кастомні хуки

## Робочий процес

Гілка на задачу → Pull Request → рев'ю → merge у main.
Задачі — у Trello, дизайн — у Figma.
